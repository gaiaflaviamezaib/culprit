The problem

You know a product irritated you. You don't know which ingredient.

Most people stop using the product and move on. The irritant is still in the next bottle they buy, under a slightly different name: parfum, aroma, linalool, lavandula oil.

Dermatologists solve this with patch tests and by comparing the products a patient reacted to with the ones they tolerate. Culprit does that second part for you, every day, with measurements instead of memory.

Under the hood

Built on the YouCam AI Skin Analysis API

Each check-in sends one selfie to Perfect Corp's YouCam API (V2). The API returns a score from 1 to 100 for each skin concern, where higher means healthier skin. Culprit combines redness, breakouts and texture into an irritation index and compares it before and after every product you start.

  1. POST /fileRegister the photo and get a secure upload link
  2. PUTUpload the selfie
  3. POST /task/skin-analysisAsk for redness, acne, texture, pore, oiliness, moisture
  4. GET /task/skin-analysis/{id}Poll until the scores are ready

Culprit turns this into: irritation index 36.5 (100 minus the weighted redness, acne and texture scores), compared with your days before each new product.

FAQ

Questions

Is this a medical diagnosis?

No. Culprit finds patterns in your own data. Only a dermatologist and a patch test can confirm an allergy. For a severe or lasting reaction, see a doctor.

Why start one product at a time?

If two new products start the same week, nobody can tell which one caused a change. Culprit flags these overlaps and gives them less weight. About a week between new products works best.

How can an ingredient be "cleared"?

If you use a product with that ingredient and your skin stays calm, it is probably not the problem. The exception is acids, retinoids and drying alcohols, which can be fine at low strength and irritating at high strength, so they are never cleared this way.

What if a product has no barcode?

Paste the ingredient list from the label or the brand's website. Culprit cleans it up and merges synonyms automatically.

Which YouCam API does it use?

The AI Skin Analysis API (V2), with six standard-definition concerns: redness, acne, texture, pore, oiliness and moisture.
